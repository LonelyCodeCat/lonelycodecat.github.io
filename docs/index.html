Method, sources & findings

Each observation uses the USD amount in Apple’s own 10-K for that fiscal year. The extraction matches the reporting year, keeps 52- or 53-week periods, and excludes quarterly and comparative values. The CSV keeps the filing accession number alongside each observation.

In FY2023 both measures fell. In FY2024 sales rose about 2%, while operating income rose about 8%. The percentage change shown in the chart compares the selected year with the preceding observation.

This portfolio example takes inspiration from EdgarTools’ approach to working with filings. The extraction and chart were built for this site.
